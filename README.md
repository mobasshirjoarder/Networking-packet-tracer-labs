# Cisco Packet Tracer - Home Network Configuration

## Overview
This repository contains a Cisco Packet Tracer lab focused on configuring a home wireless router, DHCP settings, and client devices.

- Set up DHCP Server pools and IP configurations
- Verified connectivity across Office PC and Cable Modem
- Achieved 100% completion on Activity Results
